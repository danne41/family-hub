# Family Hub 0.9.1 — iPad portrait navigation

Fixar stående iPad och mobil med kompakt toppmeny. Tryck **☰ Meny** för att öppna navigering och **✕ Stäng** för att dölja den. Menyn stängs automatiskt när du väljer en vy. Liggande större iPad behåller sidomenyn.

Alla befintliga funktioner och Stripe/Supabase-filer är kvar. Behåll din egen fungerande `config.js`. Ingen SQL eller ny Edge Function behövs för denna layoutfix. Betalningsfelet behöver felsökas separat.

Ladda upp alla projektfiler till `Develope`, inklusive nya `responsive-nav.js`.
